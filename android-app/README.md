# Белая Мгла Android

Нативная Android-оболочка для сайта https://belaya-mgla-sova58.github.io/

## v1
- отдельная иконка и запуск как обычного приложения;
- внутренние страницы открываются внутри приложения;
- внешние ссылки открываются браузером или подходящим приложением;
- кнопка Android «Назад» работает по истории сайта;
- есть индикатор загрузки и офлайн-экран;
- JavaScript, LocalStorage и Firebase-запросы сайта поддерживаются WebView.
