🦉 Сова-сканер рюкзака Тест • 4 столбца

Загрузите скриншот игрового рюкзака. Сова разделит его на ячейки, попробует прочитать количества и покажет каждый предмет отдельно. Бесплатно, без платного ИИ. Распознанные числа нужно проверить.

1. Загрузить скриншот

Можно выбрать несколько скриншотов. Они не загружаются на сервер сайта: обработка происходит в браузере. Языковая OCR-модель загружается при первом запуске.

На изображении появятся рамки найденных ячеек
Начните с загрузки скриншота.
Если рамки не совпадают с предметами

Подстройте начало сетки и расстояние между ячейками ползунками ниже. Для скриншотов вида 720 × 1280 настройки уже подобраны по присланному игровому скриншоту. Изменение рамок сбрасывает непроверенное распознавание текущего кадра.

Ограничения тестового распознавания

Пока распознаются преимущественно количества в нижней части иконки. Для названий используются выпадающие списки, потому что OCR не способен надёжно отличать предметы только по рисунку. После проверки цифр можно экспортировать результаты. Знакомые иконки постепенно добавим в каталог образцов для автоматической идентификации.

2. Проверка распознанного

0 предметов

Проверяйте число рядом с каждой иконкой. Пустые или неправильные значения можно исправить вручную. Название выбирайте только если уверены.

Это рабочий прототип для чисел. Автоматическое распознавание названий всех предметов и передача в «Совину копилку СВС» будут добавлены только после проверки качества на разных скриншотах.
