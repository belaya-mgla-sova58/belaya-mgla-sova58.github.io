## Как сохранить доказательства отдельно от сайта

Рекомендуется периодически скачивать полную копию проекта **вместе со всей историей Git**, а не только видимые страницы. Например, на компьютере с установленным Git:

```bash
git clone --mirror https://github.com/belaya-mgla-sova58/belaya-mgla-sova58.github.io.git
```

Команда создаст папку `belaya-mgla-sova58.github.io.git` с зеркалом репозитория и доступной историей. Храните её в нескольких местах, к которым имеете доступ только вы. Для последующего обновления зеркала откройте его папку и выполните `git remote update`.

Также сохраните **вне GitHub**:
- подтверждение владения и восстановления доступа к GitHub-аккаунту;
- исходные рабочие файлы, созданные вами тексты и макеты с датами;
- переписки, в которых обсуждались и согласовывались создание и изменения сайта;
- архивные копии страниц и публикаций с датами;
- разрешения или условия использования чужих материалов.

Не размещайте здесь паспортные данные, персональную переписку, пароли, токены доступа или закрытые сведения.
